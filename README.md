# One Word for Your Wi-Fi — entry

A program/v1 entry for the make.fun "One Word for Your
Wi-Fi" bounty. `main.py` writes one word to
`/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt`
when that variable is set).

The word:

Gigabit in its heart; dial-up in its conduct. See
`CANDIDATES.md` for the full draft list this winner was
picked from.
